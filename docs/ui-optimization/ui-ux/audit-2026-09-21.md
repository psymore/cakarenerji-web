# UI/UX audit (2026-09-21)

Scope: 23 routes × 4 widths (1440, 768, 390, 320), production build on localhost. Tools: axe-core (wcag2a/2aa/21aa/best-practice), Lighthouse, keyboard run, screenshots. Scripts in `scripts/`. Nothing here touches the live site.

## Findings and status

| # | Finding | Status |
|---|---|---|
| 1 | Mobile hero: upper half empty, grid only at the bottom | **Open**, not changed |
| 2 | Mobile cookie notice covers about a quarter of the screen and overlaps the hero phone link; it is also the mobile LCP element | **Open** |
| 3 | Heading order (axe: 48 pages / 62 nodes): contact card `h4` under `h2`; mobile menu labels were `h2` before the page `h1` | **Fixed** except the six blog post pages, where the body `h3` follows the `h1` directly (6 pages / 6 nodes left) |
| 4 | No skip link | **Fixed** ("İçeriğe geç", visible on focus, target `#main`) |
| 5 | Small tap targets (avg 8.7 per page under 44 px) | **Fixed**: avg 2.0 desktop and tablet, 1.8 mobile, 1.6 at 320 px. Left: blog list titles (35 px tall, large text) and a few inline links |
| 6 | Logo `aria-label` did not contain the visible text | **Changed**; Lighthouse still flags it (Turkish `İ` lowercases to `i̇`, so the check is a false positive in practice). Low priority |
| 7 | No meta description | **Open**, needs owner text: `OPEN-QUESTIONS.md` Q-25 |
| 8 | Mobile menu did not lock page scroll | **Fixed** (CSS `html:has(.drawer[data-open="true"])`) |
| 9 | Blog "Continue Reading" is English | **Left as is** (live text, `docs/route-must-haves.md`) |

Open items are tracked in `../backlog.md` (findings 1, 2 and 7 are UIO-04, UIO-02/03 and UIO-08; leftovers of 3, 5 and 6 are UIO-05, UIO-10 and UIO-07).

## What already worked

Colour contrast (axe passed), one `h1` per page, `lang="tr-TR"`, `main` landmark, form labels, page titles, CLS 0. Keyboard: Tab order sensible, 3 px focus ring everywhere, dropdown opens with Enter and closes with Esc and outside click, mobile menu closes with Esc, `prefers-reduced-motion` respected.

## Remaining Lighthouse items

Mobile LCP 4.4 s (cookie notice), `label-content-name-mismatch` (see 6), missing meta description, 28 KiB unused JS and 13 KiB legacy JS (framework), 154 ms render-blocking CSS (Next's own stylesheet), 6 font files 358 KB.

## Not covered

Screen reader run, real devices, scroll performance, forms beyond their labels (they are mailto stand-ins, see `docs/route-must-haves.md`).
